Open Source Intelligence (OSINT) Operational Methodology

Open Source Intelligence (OSINT) is the structured collection, verification, correlation, and analysis of publicly available indicators across internet registries, DNS/RDAP infrastructure, Certificate Transparency logs, corporate tax filings, official gazettes, and developer repositories to produce auditable security and due-diligence decisions.

PHASE 01

Planning & Scope

Define target organization, domains, 14-digit CNPJs, IPv4 ranges, or handles inside an auditable Investigation Case.

PHASE 02

Collection

Query Registro.br/IANA RDAP, authoritative DNS, crt.sh, BrasilAPI QSA, Shodan InternetDB, OTX, and GitHub events.

PHASE 03

Normalization

Normalize tax identifiers, deduplicate CT log subdomains, resolve active A records, and extract commit author emails.

PHASE 04

Neural Correlation

Correlate domain registrant CNPJ with QSA officers, unpatched CVEs, and Strix DAST posture via Granite 4.2 Uncensored.

PHASE 05

Dissemination

Export structured JSON evidence bundles and Shift-Left remediation snippets for engineering, legal, or red-team action.
